# 历史组合 · 本机操作手册

> 触发词：**历史组合**。用户说出这句话时，直接执行本 skill，不要先反问口径。
> 一句话：今天首板股里，哪些股票历史上曾在同一天一起首板；那个首板梯队里，后来谁走出了 4 连板+。

## 一、交付方式（每次都要做）

1. 本机主输出目录默认是 `~/桌面/临时文件`；可通过 `DESKTOP_DIR` 环境变量或 `--out` 参数覆盖，不使用旧机器的 Windows/OneDrive 路径。
2. 生成 `历史组合_<YYYYMMDD>.html`（单文件，CSS 内联，无外部 JS/CSS/字体/图片依赖，不再交付 md）：
   - 主交付：`~/桌面/临时文件`；
   - 留档：`~/.dsh/skills/history-combo-derive/pipeline/output/` 同名文件；
   - 两边内容必须一致（hash 相同）。
3. 同一天重复生成时覆盖当天这一份；不要复用昨天的文件。
4. 对话里给出结论摘要（组合 + 4 板+ 名字 + 最近重演），并附文件完整路径。

## 二、一键执行

```bash
"$HOME/.dsh/skills/.venv/bin/python" "$HOME/.dsh/skills/history-combo-derive/pipeline/derive.py"
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--date 20261030` | 指定交易日（默认取东财最近交易日） |
| `--no-fetch` | 只用本地缓存，不联网 |
| `--out <dir>` | 指定输出目录（默认 `~/桌面/临时文件`） |

脚本行为：

1. 取最近交易日（东财 `qdate`）；
2. 抓当日东财涨停池（行业、封单、炸板、流通市值）；
3. 抓当日 + 缺失历史的同花顺涨停池与连板梯队（约近一年，增量缓存）；
4. 构建每日首板梯队、追踪后续最高连板、找与今天的同日重合；默认跳过概率模型训练，只计算表格所需结果；
5. `render()` 生成四列表格的 Markdown 中间文本，`report_html.py` 用 Python-Markdown 转成带响应式表格的单文件 HTML，写桌面 + `pipeline/output`；不要把中间 md 作为交付文件。

数据缓存：`~/.dsh/skills/history-combo-derive/pipeline/data/day_*.json`（历史）、`em_*.json`（当日东财）。
首次全量约 3 分钟；之后每天只补 1 天。

## 三、口径（必须遵守，不要临时改）

1. **今日首板**：涨停池中“当前连续高度 = 1”的股票。
   - 连板梯队接口只收录 2 板及以上；**不在梯队里的涨停股，当前高度就是首板**。
   - 不要用 `high_days` 的“N 天 M 板”直接当连板数：`3 天 2 板` 当前可能是首板（中间断过）。
2. **历史同日重合**：今天首板代码 ∩ 历史某日首板代码，**≥2 只**才算“组合”。
3. **4 板+**：从首板日起连续涨停 ≥4 个交易日（含首板当天），不是“再涨 4 天”。
4. **主组合选择**：先看“4 板+ 个股是否在重合组合内”，再看重合只数，最后看日期。
5. **板块子组合**：用东财行业给重合股分组，取最大同行业组（≥2 只）作为“白酒 4 只”这类板块组合。
6. **最近重演**：所有“有 4 板+ 的重合日”里日期最新的一个；**反例**：重合只数最多但没有 4 板+ 的日期，也要写。
7. **4 板+ 名字是历史结果，不是对今天的预测**。报告里必须写这句，避免误导。

## 四、输出结构（精简单表）

HTML 默认只展示一张四列表格，不再输出连板天梯、概率排序、个股记忆厚度等分析段落。

| 列 | 内容 |
|---|---|
| 当前首板组合 | 今天首板中，曾在该历史日一起首板的全部股票及重合只数 |
| 历史共同首板日 | 重合发生日期，并标记主组合、最近重演或反例 |
| 同梯队历史龙头 | 该历史首板梯队后来走出 4 板+ 的股票；若也在当前组合内，标记“组合内” |
| 龙头最高连板 | 截至当前交易日观察到的最高连续板数，与龙头逐行对应 |

- 所有有 4 板+ 龙头的历史重合日均保留，另外保留主组合和最大反例，不能只展示成功案例。
- 排序：主组合第一、最近重演第二，其余优先“龙头在组合内”、重合只数和日期。
- 页脚只需一句口径说明：板数截至当前交易日，历史结果不是对今天的预测，4 板+ 含首板当天，不构成投资建议。
- 旧七段渲染保留在 `render_verbose()`，默认不调用；`analyze(..., detailed=False)` 默认不训练概率模型，避免无效耗时。

## 五、数据源与边界

| 源 | 用途 | 边界 |
|---|---|---|
| 东财 `getTopicZTPool` | 当日涨停池、行业、封单、炸板、流通市值 | 基本只有当前日；历史日期会**静默返回当前日**，必须校验 `qdate` |
| 同花顺 `limit_up_pool` | 每日涨停池（首板、原因、封单、换手、市值） | 只回溯约 1 年；旧日期 `status_code:-1`；`limit` 最大 200 |
| 同花顺 `continuous_limit_up` | 每日 2 板+ 的精确高度 | 不含首板；不在梯队 = 当前首板 |

- 当前日若同花顺池尚未更新（傍晚前），脚本回退东财当日池；历史仍用同花顺。
- 北交所不在同花顺 `HS,GEM2STAR` 口径内，报告不统计。
- 行业用东财 `hybk`；历史股没有行业映射，板块子组合只对“今天首板股”分组。

## 六、坑（都踩过）

1. **东财历史静默回当前日**：HTTP 200、`pool` 可能为空或仍是当前日，必须看 `qdate`。
2. **同花顺只有近一年**：2025-10 之前的日期取不到，不要承诺“多年历史”。
3. **`limit` 超过 200 直接报错**：`limitmust be less than or equal to 200`。
4. **“3 天 2 板”不是 2 板**：以连板梯队高度为准；不在梯队按 1 板。
5. **最近重演可能尚未走完**：表头写“最高连板”，页脚写“截至当前交易日”，不能误写成已经结束的最高板。
6. **不要计算已隐藏的概率模型**：默认 `detailed=False`；旧逻辑回归训练耗时很长，精简表格不需要它。
7. **反例不能漏**：至少保留重合只数最多且没有 4 板+ 的日期，避免只看好的一面。
8. **中文编码**：脚本和报告统一使用 UTF-8；不要在非 UTF-8 控制台直接判断中文内容。
9. **桌面路径**：本机默认 `~/桌面/临时文件`，可用 `DESKTOP_DIR` 或 `--out` 覆盖，不要写死旧机器路径。
10. **同日重跑覆盖**：文件名带日期，同一天只保留一份；不要追加。

## 七、验收（生成后自检）

- 今日首板数 = 东财 `lbc == 1` 的数量；2026-10-30 基线：**47 只涨停 / 38 只首板**。
- HTML 只包含 1 张表、4 列，不出现 `<h2>` 分析段落；表头必须为“当前首板组合 / 历史共同首板日 / 同梯队历史龙头 / 龙头最高连板”。
- 数据存在时，页面应有“主组合”“最近重演”“反例”标记；历史龙头在当前重合组合内时应有“组合内”标记。
- 每个展示板数都要用原始连板梯队逐日复核；组合中的每只股票必须同时是目标日首板与对应历史日首板。
- 1440 / 390 宽度下 `document.body.scrollWidth <= innerWidth`；长表允许在自身容器横向滚动，不能撑破 body；无外部资源依赖。移动端测试若注入输出节点，必须隐藏，避免测试脚本自身撑宽页面。
- 2026-10-30 基线：主组合 **古井贡酒、泸州老窖、皇台酒业、迎驾贡酒（+ 派斯林，5 只）**，历史同日 **2026-01-29**，4 板+ **皇台酒业（4 板，1/29~2/3）**，同梯队另有 **万丰股份、横店影视（4 板）**。
- 2026-11-02 基线：125 只涨停 / 114 只首板；主日 **2026-10-09**，重合 13 只，4 板+ 为 **百洋股份 5 板、慈文传媒 5 板、新经典 4 板**；最近重演 **2026-10-28 → 澳洋健康 4 板**。
- 2026-11-12 精简单表基线：26 只首板、26 条组合记录；主组合 **九牧王、吉视传媒、百洋股份**，历史日 **2026-10-09**，龙头 **慈文传媒 5 板、百洋股份 5 板、新经典 4 板**；最近重演 **2026-11-09，澳洋健康、龙建股份 → 东方环宇 4 板（截至当日）**。
- 桌面文件与 `pipeline/output` 同名 HTML hash 一致：
  ```bash
  cmp -s "$HOME/桌面/临时文件/历史组合_<YYYYMMDD>.html" \
    "$HOME/.dsh/skills/history-combo-derive/pipeline/output/历史组合_<YYYYMMDD>.html" \
    && echo "hash 一致"
  ```

## 八、脚本不可用时的兜底

若 `derive.py` 丢失：

1. 按本 skill 第五节的接口重新抓数；
2. 用 `pipeline/fetch_all.py` + `pipeline/analyze.py`（旧版脚本）先出 `report.txt`；
3. 按第四节精简四列表格手工组单文件 HTML（可以保留 Markdown 作为中间文本，但最终交付必须是 `.html`）；
4. 核心口径不变：不在连板梯队 = 首板；4 板+ = 连续 ≥4；重合 ≥2 才算组合。
