# history-combo-derive：历史组合

## 1. 这个技能做什么

把今日首板股放回近一年历史，寻找它们曾在哪些交易日“一起首板”，再追踪那些历史首板梯队后来走出的4连板及以上个股。输出包含主组合、最近重演、反例、概率模型和个股记忆厚度的单文件HTML。

报告中的4板+是历史复盘结果，不是对今天股票的确定性预测，也不构成投资建议。

## 2. 触发词与成品

- 触发词：“历史组合”“组合看板”“首板历史组合”“同日首板组合”。
- 成品：`历史组合_<YYYYMMDD>.html`。
- 默认写入 `~/桌面/临时文件`，同时留档到 `pipeline/output`。
- 同一天重跑覆盖当天文件，不复用昨天结果。

## 4. 本机环境

使用 Python 3.8+ 和共享隔离环境 `~/.dsh/skills/.venv`。需要重装依赖时执行：

```bash
"$HOME/.dsh/skills/.venv/bin/python" -m pip install -r "$HOME/.dsh/skills/history-combo-derive/pipeline/requirements.txt"
```

依赖为 `requests`、`Markdown`、`chardet`。为兼容本机 kysec 对第三方原生库的限制，逻辑回归使用纯 Python 实现，不再需要 NumPy。需要访问东方财富和同花顺数据接口。日常生成不需要Chrome；只有额外做浏览器宽度验收时才需要Headless Chrome。

## 5. 日常执行

在 Bash 中：

```bash
"$HOME/.dsh/skills/.venv/bin/python" "$HOME/.dsh/skills/history-combo-derive/pipeline/derive.py"
```

常用参数：

```bash
PY="$HOME/.dsh/skills/.venv/bin/python"
SCRIPT="$HOME/.dsh/skills/history-combo-derive/pipeline/derive.py"

# 指定交易日
"$PY" "$SCRIPT" --date 20261103

# 只用本地缓存，不联网
"$PY" "$SCRIPT" --date 20261103 --no-fetch

# 指定主输出目录；项目output仍会留档
"$PY" "$SCRIPT" --out "$HOME/桌面/临时文件"
```

不传日期时，脚本通过东财最近交易日和本地缓存判断目标日。默认主输出为 `~/桌面/临时文件`，也可设置 `DESKTOP_DIR`。迁移包已经带历史数据，通常每天只增量补最新一天。

## 6. 核心口径

1. **首板**：当前连续高度为1。同花顺连板梯队只收2板+，不在梯队中的涨停股按首板处理。
2. **不能直接用N天M板**：例如“3天2板”可能中间断板，当前实际为首板。
3. **组合**：今日首板代码与历史某日首板代码交集至少2只。
4. **4板+**：从首板日起连续涨停至少4个交易日，含首板当天。
5. **主组合排序**：优先4板+是否在重合组合内，再看重合只数，最后看日期。
6. **最近重演**：有4板+的重合日中取最新一天；同时列出“重合多但无4板+”的反例。
7. **行业子组合**：行业只来自今日东财 `hybk`，不给历史股补造行业映射。

## 7. HTML固定结构

1. 直接结论：组合、历史同日、4板+、最近重演、反例。
2. 今日连板天梯，首板按行业分组。
3. 历史同日首板重合表。
4. 主组合和最近重演案例拆解。
5. 今日4板+概率排序，含验证AUC和基准率。
6. 个股“同梯队4板+”记忆厚度。
7. 方法与局限。

`render()` 生成的Markdown只是中间文本，最终交付必须是 `.html`。

## 8. 随包数据

`pipeline/data` 已完整保留原机约22MB缓存，涵盖2025-10-15至2026-11-03可用的同花顺交易日数据及东财快照。接口只提供约近一年历史，不能承诺更早数据。

保留缓存的作用：新机器可立即用 `--no-fetch` 重建2026-11-03报告，并避免重新请求全部历史。后续新增交易日会在同目录增量写入。

## 9. 验收与排坑

- 今日首板数应等于东财 `lbc == 1` 的数量。
- HTML应有7个 `<h2>`、4张表，主结论嵌套列表不能残留字面 `   -`。
- 1440/390宽度下body无横向溢出；长表只允许自身容器滚动。
- 桌面与 `pipeline/output` 同名HTML的SHA-256一致。
- 东财历史请求必须看 `qdate`，HTTP 200不代表返回了请求日。
- 同花顺 `limit` 最大200；旧日期可能返回 `status_code:-1`。
- 当前日同花顺尚未更新时，脚本回退东财当日池，历史仍用同花顺。
- 北交所不在 `HS,GEM2STAR` 口径内，报告不统计。
- 本机默认桌面为 `~/桌面/临时文件`；需要更换目录时设置 `DESKTOP_DIR` 或显式传 `--out`，不要使用旧机器的 Windows 路径。

## 10. 兜底说明

只有主脚本不可用时才考虑 `fetch_all.py` 与 `analyze.py`。它们是旧版辅助脚本，部分日期和输出形式已固定，运行前必须检查并调整；最终仍需按七段结构生成HTML，核心首板和4板+口径不能改变。
