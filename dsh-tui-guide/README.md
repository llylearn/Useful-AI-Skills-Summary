# dsh-tui-guide

## 用途

回答 dsh-tui 的安装、日常使用、交互、配置、主题、后端、插件、CLI、VS Code 和会话迁移问题。用户明确询问 dsh-tui 时使用，普通编码任务不加载。

## 内容

- `SKILL.md`：手册索引、语言选择、检索方法和路由表。
- 中英文 Markdown 手册：中文无后缀，英文使用 `.en.md`。
- 无脚本、无第三方 Python 依赖。

## 使用与迁移

将整个目录安装到 `~/.dsh/skills/dsh-tui-guide`，或随根目录 `install.py` 安装。回答时先按主题检索，再读取相关小节，并注明“文件名＋小节标题”；手册未记录的行为不要编造。

本包是 2026-11-11 的快照。若目标机 dsh-tui 版本较新，以目标机自带手册为准，不要用旧行为覆盖新版本事实。
