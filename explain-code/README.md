# explain-code

## 用途

面向“前端转后端”的学习者讲解代码，不只是翻译语法，而是按 **整体作用 → 逐行／逻辑块 → 数据流 → 技术名词总结** 展开，并优先使用 TypeScript、Express/Koa、组件 props 等前端类比。

## 触发示例

- “讲解这段代码”
- “逐行解释这个 Go/Java 文件”
- “以前端视角讲代码”

## 内容与依赖

- `SKILL.md`：完整技能规则。
- `使用说明.md`：输入、输出和恢复方法。
- 无脚本、无第三方依赖。

迁移时复制整个目录，不要只复制其中一份说明。若新用户不再具有前端背景，应先调整 `SKILL.md` 中的用户背景与类比方式，不要机械沿用前端类比。
