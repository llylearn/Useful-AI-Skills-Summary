# explain-code：代码讲解技能

## 1. 用途

面向“前端转后端”的学习者讲解代码。不是只翻译语法，而是按“整体作用 → 逐行/逐块解释 → 数据流 → 技术名词总结”的顺序，把后端代码映射到熟悉的前端概念。

## 2. 触发方式

可直接说：

- “讲解这段代码”
- “逐行解释这个 Go/Java 文件”
- “以前端视角讲代码”

也可以显式调用：`/explain-code`。

## 3. 输入与输出

- **输入**：一段代码、一个文件，或指定要讲的函数/类。
- **输出**：中文讲解；每行或逻辑块尽量包含大白话、语法点、包/函数来源、入参、返回值和错误处理。
- **第三方包**：除解释用途外，还会说明“不用它需要自己做什么”。
- **结尾**：用正式技术名词概括，帮助从前端类比过渡到后端术语。

## 4. 核心规则摘要

1. 先说明代码在系统里的角色，再进入细节。
2. 优先使用 TypeScript、Express/Koa、EventEmitter、组件props等前端类比。
3. 后端特有语法单独解释，例如指针、结构体标签、defer、goroutine、ORM、中间件和依赖注入。
4. 不假设读者已经懂后端，但不重复堆砌无关概念。
5. 多步骤代码可补充数据流，例如“请求 → 参数绑定 → 查询 → 响应”。

| 文件 | 说明 |

## 6. 新机器恢复

把整个 `explain-code` 文件夹复制到：

```text
~/.dsh/skills/explain-code
```

DSH 会监视该目录并刷新技能目录；在 dsh-tui 中可用 `/skills` 检查，然后用“讲解代码”或 `/explain-code` 触发。
