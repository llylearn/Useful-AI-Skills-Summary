# weekly-report

## 用途

将一周的零散工作记录整理成成果视图，按 **项目 → 前端/后端 → 【已上线】/【开发中】 → 编号事项** 组织，并合并同一任务的多次记录。

## 使用条件

用户提到“周报／个人周报／weekly report”并同时提供工作记录。标签优先于内容推断；不留空标题，不在正文输出进度百分比，不搬运无业务意义的参数名、变量名或文件路径。

## 文件与落盘

- `SKILL.md`：完整生成规则与检查清单。
- `使用说明.md`：补充使用信息。
- 无脚本和第三方依赖。

默认在对话中输出；只有用户明确要求落盘时才生成 `周报_<日期>.txt`。桌面由 `DESKTOP_DIR` 指定，迁移后必须设置为目标机的真实目录，不要沿用原电脑路径。
