# smart-sensing-youth-post

## 用途

把项目记录、简报或零散素材整理为“智能感知青年突击队”微信公众号通讯稿，突出战略背景、部署推进、技术攻坚、质量协同、量化成果和青年担当。

## 触发示例

- “写一篇智能感知青年突击队推文”
- “整理青年突击队通讯稿”
- “写智能感知项目宣传稿”

## 核心边界

所有人物、数字、日期、引语、荣誉、验收结果和照片内容都必须有素材依据；严格区分已完成、进行中和计划。缺少关键事实时先追问，或按用户要求标【待补充】，不得编造。

## 内容与迁移

包含 `SKILL.md` 和 `使用说明.md`，无脚本或第三方依赖。若目标团队、栏目、篇幅或文风不同，先修改技能定义，不要把“智能感知”名称套到其他团队。
