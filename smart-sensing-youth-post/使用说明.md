# smart-sensing-youth-post：智能感知青年突击队推文

## 1. 用途

把项目记录、工作简报或零散素材写成“智能感知青年突击队”微信公众号通讯稿。重点不是堆口号，而是呈现：战略背景、具体难题、技术行动、量化成果、现场细节和青年担当。

## 2. 触发方式

- “写一篇智能感知青年突击队推文”
- “整理青年突击队通讯稿”
- “把这些项目素材改成智能感知项目宣传稿”
- “仿写企业青年团队攻坚文章”

也可显式调用：`/smart-sensing-youth-post`。

## 3. 素材要求与事实边界

只使用用户提供或能够核实的事实。尤其不能虚构：人物、日期、数字、引语、荣誉、客户评价、领导讲话、验收结果和照片内容。

- 严格区分“已完成、正在推进、计划开展”。
- 缺少关键事实时先简短追问；用户要求先出草稿时，用醒目的【待补充】。
- 技术功能不能夸大，供稿、审核和图片署名未提供时不自行补写。

## 4. 文章结构

默认采用“项目攻坚型”：总起 → 部署推进 → 技术攻坚 → 质量/安全保障 → 成果 → 价值与下一步。科技创新素材可改为“已有基础 → 当前突破 → 应用价值 → 后续规划”。

每个重点段落尽量形成：

```text
遇到什么困难 → 采取什么行动 → 解决得怎样
```

默认800—1200字，素材少时精简，不为篇幅重复凑字。标题默认只给一个最推荐版本，用户需要时再给备选。

## 5. 输出与验收

默认直接输出可编辑的完整稿件，不附写作分析。交付前检查：标题点明团队与任务；开头交代背景、主体、任务和成果；至少一个具体行动或现场；数字与引语有依据；结尾回应项目价值且不堆叠口号。

## 6. 文件、依赖与恢复

|---|---|

| `使用说明.md` | 本说明 |
