## 文件

| 文件 | 作用 |
|---|---|
| `fetch_kaipan.py` | 开盘啦历史涨停池 2020-01-01 ~ 2026-11-10 -> `kaipan_history.json`,可断点续跑 |
| `fetch_current.py` | 东财当前涨停池 -> `current_pool.json` |
| `fetch_kaipan_detail.py <date>` | 开盘啦某日各板位详情,回填历史池(`detail=true`) |
| `fetch_concepts.py` | 东财概念板块反扫 + 行情资料 -> `stock_extra.json`(领涨概念前二 + 行业 + 地域),同一天可断点续跑 |

| `build.py` | 组装单文件 HTML -> 项目目录 + `~/桌面/临时文件/对比看板_<YYYY-MM-DD>.html` |
| `check.py` | Python 层自检 |
| `template.html` | 新版式模板(hero/七宫格/共同胶囊/吸顶头/居中轴,日期由 `@@CUR_DATE@@` 等占位符注入) |

## 换当前交易日

同步改这些硬编码:`fetch_kaipan.py` 的 `END`/`CUR_DATE`、`fetch_current.py` 的 `CUR_DATE`、
`compare_section.py` 的 `CUR_DATE`；`build.py` 自动读取 `section_data.json` 的 `cur_date`。然后:

```powershell
Set-Location "$HOME\.dsh\skills\lianban-duizhao\pipeline"
$PY = "$HOME\.dsh\skills\.venv\Scripts\python.exe"
& $PY fetch_kaipan.py            # 增量补新日期
& $PY fetch_current.py
& $PY compare_section.py         # 首次会提示缺详情
& $PY fetch_kaipan_detail.py "<对照日>"
& $PY compare_section.py
& $PY fetch_concepts.py          # 领涨概念+行业(同一天可断点续跑,跨天自动重扫)
& $PY compare_section.py
& $PY build.py
& $PY check.py
& $PY browser_check.py
```

## 口径(与 SKILL.md 一致)

- 历史源:开盘啦 `apphis.longhuvip.com`(2020 起,无北交所);当前源:东方财富 `getTopicZTPool`。
- 周期排除:当前最高标首板日及之后不参与历史对照。
- 单日涨停 > 250 只不做对照(MAX_HIS=250)。
- 重叠分母 = 当前池中历史源覆盖的代码数(北交所不计)。
- 历史卡标签只用当日涨停原因(`[5]`);`[12]` 所属板块会回填当前概念,历史不用。
- 历史源无炸板次数,弹窗显示 `—`;当前卡炸板次数来自东财 `zbc`。
- 所属地域取东财行情接口 `f128`(去掉「板块」后缀),显示在输赢前;历史股使用当前地域分类,无源数据时留空。
- 地域／输赢行下独立显示 `封单 金额 / 手数`:当前收盘价取东财 `p ÷ 1000`,历史收盘价取开盘啦详情 `[21]`;
  手数 = 收盘封单额 ÷ 当日收盘价 ÷ 100,属于换算约值;缺数据用 `—`,不得编造。
- 同梯队战绩:3 板+ 同板数,次日 lb = 当日 lb+1 判晋级;统计整个历史池。
- 与 SKILL.md 原版口径的差异:当前卡标签用东财领涨概念前二(概念板块按当日涨幅反扫,
  无同花顺源);晋级判定用历史源板数(未接腾讯日K)。
- 东财 push2 限流:fetch_concepts.py 已带 UA/重试/断点续跑;失败板块自动跳过。
- 若 push2 限流且开盘啦当日数据未发布,缺概念的当前卡退回东财涨停池行业标签并在页脚注明「非领涨概念」。
